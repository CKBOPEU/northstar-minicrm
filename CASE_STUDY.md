# Northstar MiniCRM — case study

A self-directed portfolio concept for a small creative studio. The goal was to keep opportunities, people and next actions visible without the density of an enterprise CRM.

The result combines a four-stage kanban pipeline with contacts and tasks. Cards expose deal context and offer explicit stage movement; forms support creation and editing. The responsive layout keeps each stage readable as a horizontally navigable board on phones. English and Russian are built into the interface.

The app uses React, Next.js and TypeScript with versioned browser storage and validation on both writes and reads. Five domain tests cover valid seed data, field validation, normalization, stage transitions and rejection of corrupt storage.

This is a local demonstration with fictional records and illustrative values, built with Codex assistance. It has no clients, commercial results, backend, authentication, payments or messaging. A production system would add server-side authorization and validation, transactional storage, audit history, privacy controls and backups.
